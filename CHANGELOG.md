# Changelog

Version numbers are `MAJOR.MINOR.PATCH` (shown in Settings → About):

- **PATCH** (1.0.0 → 1.0.1): fixes, wording and small look changes.
- **MINOR** (1.0.x → 1.1.0): new features.
- **MAJOR** (1.x → 2.0.0): changes that need action from users (for example a new
  backup format, or approvals that no longer match).

## 1.0.1 · 2026-11-27

User guide updated for version 1.0.0: new screenshots (company logo in the top bar,
line icons, question boxes, two-column tools table), a new Settings section
(appearance, keyboard shortcuts, About), and the new PDF file names.

## 1.0.0 · 2026-11-27

First numbered version. It includes everything built so far: products by line and
machines, steps with sub-steps, notes and up to 3 photos, photo markup, safety
signs, tools, machine settings, PDF export (single and ZIP), approvals with
digital signatures, access codes and roles, logs, backups and import, offline use,
the ⋮ menus, Settings with appearance (light or dark) and keyboard shortcuts.
New in this version: the version number in Settings → About, the company logo or
name in the top bar, and a one-line backup reminder on the Home page.
